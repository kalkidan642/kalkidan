The project description is as follows:
1. Title of the project:
	Student portfolio 
2. project Description 
	the project contains 6 menus such as:
		Home: which shows the default page which is index.html
		About Me: which explains the detail about the student such as name, school, interest, department, student status,  etc
		Skills: which shows about what a student can do and what they are good at 
                Project: which shows about the project that has been created and worked on before by the students
                contact us: This section provides a way to communicate with me though my contact information
3. Technologies Used:
             HTML, CSS, JavaScript
4. Features Used:
            Dark/light theme, Image slider, Typing animation, Digital clock, Current date and time, Search function, Visitor counter, Download CV button, Scroll amination and Back to top button.
5. How to run:
        first download the project containing three files(index.html, style.css and script.js), then open the project folder in VS code, after that open the index.html file, open with live server, the portfolio will open in your web browser.
